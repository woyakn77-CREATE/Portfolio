MLB Payroll-Adjusted Standings

Question
What would the 2026 standings look like if every team's runs were scaled by how much it spends?
Built
A model that replays all 2,429 games of 2026 (and 2,106 from 1982), checked against official standings, with each team's runs scaled by a payroll multiplier. Penalty, bonus, cap and floor inputs re-sort the standings live. Built as an Excel workbook with live formulas and as this web simulator.
